# Verificador de força de senha

Programa em Python que avalia se uma senha é fraca, média ou forte e mostra dicas do que falta para melhorá-la. Projeto de estudo em cibersegurança.

## O que ele faz
- Lê uma senha digitada no terminal
- Verifica o tamanho e se tem letra maiúscula, minúscula, número e símbolo
- Dá uma pontuação de 0 a 4 e classifica a senha
- Mostra dicas do que falta

## Como rodar
```
python senha.py
```
Dependendo do sistema, use `python3` ou `py` no lugar de `python`.
