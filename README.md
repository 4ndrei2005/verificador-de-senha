## O que eu aprendi
Neste projeto aprendi a usar o `input` para ler o que a pessoa digita, o `for` para percorrer a senha caractere por caractere e o `if`, `elif` e `else` para tomar decisões. Também aprendi a usar variáveis, a contar pontos e a usar Git e GitHub para guardar o projeto. Ainda estou reforçando o estudo de condições (`if`, `elif`, `else`) para dominar melhor.

## Limitações
O programa só olha o tipo de caractere (maiúscula, minúscula, número e símbolo). Por isso uma senha como `P@ssw0rd` sai "forte", mesmo sendo muito conhecida. Também não leva o tamanho em conta na pontuação e não compara a senha com listas de senhas comuns. Como melhoria, pretendo adicionar essas verificações.
